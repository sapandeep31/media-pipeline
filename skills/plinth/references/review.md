# Review mode

Score an existing deck. Be blunt; the user asked for it.

1. Extract only the headlines. Does the list make the case on its own? (0 to 30)
2. One job per slide: count slides with two or more competing elements. (0 to 20)
3. Evidence: every number sourced, the demo real, the traction real. (0 to 20)
4. Craft: consistent grid, type scale, one accent, chart titles written as claims. (0 to 15)
5. Voice: run `scripts/lint-deck.mjs` and take its score x 0.15. (0 to 15)

Report the total, the three changes that would move it most, and a rewritten spine. Then offer to rebuild it on the template.
